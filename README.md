# Apple Sales Analysis Dashboard

## Project Overview

An interactive Power BI dashboard created to analyze sample Apple sales data and explore sales performance across different business dimensions.

## Objective

To analyze sales data and identify patterns across:

- Products
- Cities
- Ratings
- Payment methods

## Tools Used

- Power BI
- Power Query
- DAX

## Dashboard
![Apple Sales Power BI Dashboard](Screenshot%20%2862%29.png)
The dashboard provides interactive visual analysis of Apple sales data through multiple charts, KPIs and filters.

## Key Analysis

- Sales performance analysis
- Product-wise sales analysis
- City-wise analysis
- Customer rating analysis
- Payment method analysis

## Data Note

This project uses sample/practice data and is not official Apple sales data.
